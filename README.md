# Elysium
Elysium fields, Charon wallet integration can function via LAN or WAN

Elysium is where the "good" tokens go as they cross the river STYX. Elysium is a WEB3 market where one token can be exchanged for another like any other market or exchange. 

Where it differs:

Because of the unique nature of STYX crypto, and the CODEX/CODEX GIGAS system, you can spend or trade STYX on the Elysium platform to reveal collected data on any market by subject (dewey decimal organized).
This enables the user to connect to specific information within the MCS.DMS (Milestone commercial services database management system) that may be locally archived, historically archived, or in real time.

Example: Historical data stored regarding the weather in a specific but crucial agricultural zone can be compared against weather patterns for the current year, enabling a trader to make more accurate 
predictions on the commodities market.

By extension, providers of real time data and historical archives can transform their generated and/or curated datasets into tokens. (A small esp32 or raspberry pi weather station could generate some form 
of passive income.)

Next, Elysium can be configured and limited to WAN/or LAN only, to allow payments or transfers with NFC, smart contracts, auctions, etc.
